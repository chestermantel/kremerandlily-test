# kremerandlily-test — design preview

A **reworked design** of the Kremer & Lily wedding site ("The Engraved Suite"),
deployed to **test.kremerandlily.com** so it can be compared against the live
site at kremerandlily.com before any of it is adopted.

- Same content, tabs, and RSVP flow as production; new visual design.
- One self-contained `index.html`. Photos and flower cut-outs are referenced
  from the live site (`https://kremerandlily.com/...`) so this repo stays lean.
- `noindex`. RSVP backend is intentionally not wired here (shows "not open yet").
- The hidden Developer Tools editor is omitted from this preview.

Not the production site. Source of truth remains `chestermantel/lily-wedding-123`.
